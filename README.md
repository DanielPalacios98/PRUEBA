# PRUEBA

Repositorio experimental para automatizar el desarrollo con OpenAI Codex.

## Objetivo

Establecer comunicación entre:

- Windows
- GitHub
- Ubuntu Server
- OpenAI Codex CLI

## Funcionamiento

1. Windows modifica archivos.
2. Windows ejecuta git push.
3. Ubuntu Server detecta los cambios.
4. Ubuntu Server ejecuta git pull.
5. Codex analiza README.md y TASKS.md.
6. Codex desarrolla la tarea solicitada.
7. Codex prepara los resultados para revisión.
